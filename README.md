# Music Corner
This is solely a fun project I do using Claude. 

**Live page:** https://trieustats.github.io/music-corner/my-page.html

### Know this piece?

If you recognize it, please open an issue on this repo and tell me its name. I'd love to know. 

### Files

| File | What it is |
|---|---|
| `my-page.html` | The page itself: HTML, CSS and a little JavaScript |
| `image.png` | The original flower image, which the two images below are made from |
| `image-banner.jpg` | The top third of the flower image, shown as the banner across the top of the page |
| `image-900.jpg` | A smaller copy of the flower image, used on the spinning record in the centre of the menu |
| `looped.mp3` | The looped recording of the piece |
| `music-corner.Rproj` | RStudio project file, used for editing |

### Built with:

HTML, CSS and JavaScript, with no frameworks or build step. The Web Audio API makes the glow around the record follow the music. Fonts are EB Garamond and JetBrains Mono from Google Fonts, and CMU Serif (the LaTeX font) from [cm-web-fonts](https://github.com/aaaakshat/cm-web-fonts).
