# Music Corner
This is solely a fun project I do using Claude. 

**Live page:** https://trieustats.github.io/music-corner/my-page.html

### Know this piece?

If you recognize it, please open an issue on this repo and tell me its name. I'd love to know. 

### Files

| File | What it is |
|---|---|
| `my-page.html` | The page itself: HTML, CSS and a little JavaScript |
| `image.png` | The image on the left of the page |
| `looped.mp3` | The looped recording of the piece |
| `music-corner.Rproj` | RStudio project file, used for editing |

### Built with:

HTML, CSS and JavaScript. Fonts are EB Garamond and JetBrains Mono from Google Fonts.
